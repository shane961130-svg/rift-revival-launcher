# Contributing

Changes should be made through a branch and pull request. Explain the player-visible behavior, include focused validation, and keep launcher safety checks passing.

Do not submit proprietary game files, decompiled source, saves, credentials, private server configuration, generated executables, DLLs, archives, logs, or machine-specific paths. Tests may inspect a game installation supplied locally by its owner, but fixtures committed here must be synthetic or independently redistributable.

All contributors must use multifactor authentication on their source-hosting account before participating in a signed release. A maintainer other than the author should review release-affecting changes whenever another maintainer is available.
