# Privacy

Rift Revival does not collect telemetry, analytics, crash reports, saved games, account credentials, or personal information.

The launcher makes network requests only when the user explicitly checks for launcher updates or accepts a displayed launcher update. Those requests go to the public `shane961130-svg/rift-revival-launcher` repository on GitHub. GitHub's own privacy policy applies to those requests.

Launching Interstellar Rift uses the game and Steam networking chosen by the user. Rift Revival does not proxy or inspect that traffic.
