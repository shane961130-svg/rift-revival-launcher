# Security

Report a suspected vulnerability through GitHub's private vulnerability reporting feature for this repository. Do not include passwords, account tokens, private saves, server authentication files, or proprietary game binaries in a report.

Supported releases verify their bundled dependencies and managed game-copy records. The launcher refuses unknown source executables, modified installation records, unsafe paths, and partial updates. It does not disable or bypass operating-system security controls.

Only artifacts attached to a GitHub release in this repository are project releases. Verify the release digest before running an artifact. Code signing is planned but is not yet available; see [Code signing policy](CODE_SIGNING_POLICY.md).
