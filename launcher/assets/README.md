# Launcher assets

`hero.png`, `logo.png`, and `launcher.ico` are project artwork generated for Rift Revival. The public build does not include the private design-reference screenshot or copied game artwork.

`icons.ttf` is a lossless WOFF-to-sfnt conversion of Bootstrap Icons 1.13.1 for Windows GDI+. Its MIT licence is included as `BootstrapIcons-LICENSE.txt`.

Mono.Cecil is downloaded during the build rather than committed. Its MIT licence is included as `Mono.Cecil-LICENSE.txt`.

The text hash tables contain compatibility and integrity values for supported mod selections. They contain no executable code or game content.
